# 05 — Amortissements

> [!quote] En une phrase
> Répartir le coût d'une immobilisation sur sa durée d'usage — *la fenêtre par laquelle la direction regarde le futur* et le **levier de résultat n°1**.

## Le mécanisme
- **Définition CGNC** : amoindrissement **irréversible** de la valeur d'un actif (usage, temps, obsolescence) — étalement du montant amortissable sur la durée prévisionnelle d'utilisation (loi 9-88 art. 14).
- **Formule de base** : *Valeur d'entrée − Cumul des amortissements = VNC*.
- **Pourquoi** : refléter la dépréciation réelle, **reconstituer le potentiel financier** de renouvellement, spécialiser les exercices.

## Les comptes et méthodes

| Élément | Compte | Détail |
| --- | --- | --- |
| Dotations d'exploitation | **619x** (6191-6193) | Débit annuel |
| Amortissements (déduction d'actif) | **28xx** (281 non-valeurs, 282 incorporelles, 283 corporelles) | Crédit |
| Amortissements dérogatoires | **1351** | Logique fiscale → quasi-fonds propres |
| Linéaire | Mode de droit commun | Dotation constante = base ÷ durée |
| Dégressif | Option **fiscale** facultative (CGI art. 10-III-C-1°) | Réservée à certains biens d'équipement neufs |
| Non-valeurs (21) | Linéaire **≤ 5 exercices**, sans prorata la 1ʳᵉ année | |
| Terrains nus (2311) | **Non amortissables** (sauf gisements : épuisement) | |
| Fonds commercial (2230) | **Non amorti** — provision si dépréciation | |

**Écriture type** : D 619x (dotations d'exploitation) / C 28xx — baisse du résultat ET de la valeur nette : l'équation reste équilibrée.

## 🚨 Le message caché — l'amortissement comme levier
- **La date de départ est un choix** : « lorsqu'on voulait augmenter le résultat, on avançait un peu sur les dates de démarrage » (thèse ISCAE).
- **La durée d'usage est un choix** : allonger = dotations plus faibles = résultat plus beau.
- **Changement de méthode/durée** → justifié dans l'ETIC (A2/A3). *Si l'ETIC est muet et les dotations chutent : signal d'alerte.*
- **Comment vérifier** : ETIC B2 (immobilisations) × B2bis (amortissements) + état A3.

## Traitement fiscal
- Plafond des véhicules de tourisme : **400 000 DH TTC** (LF 2025) → **80 000 DH/an** max ; excédent réintégré (crédit-bail inclus).
- Amortissements dérogatoires (1351) : non déductibles fiscalement au sens strict — provisions réglementées, dette d'impôt latent → retraitement en quasi-fonds propres.
- Durées usuelles (bâtiments 20 ans, matériel 10 ans, transport 5 ans…) : **[standard]** — usages fiscaux CGI et professionnels, le PCGE ne les chiffre pas.
