# 07 — Messages cachés (lecture entre les lignes)

> [!quote] En une phrase
> La comptabilité marocaine n'est pas une vérité, c'est un **champ de décisions** — l'ETIC est le procès-verbal de ces décisions. Voici les **13 signaux** que l'analyste expérimenté cherche.

## Les 13 messages cachés

| Message caché | Où le chercher | Signe d'alerte | Comment vérifier |
| --- | --- | --- | --- |
| **Actif fictif** | Non-valeurs (21) | Non-valeurs élevées non amorties vs capitaux propres | ETIC B1 — déduire du bilan financier |
| **Résultat gonflé par les stocks** | Stocks (3) + variation (CPC) | Variations incohérentes vs ventes ; activation de charges financières | Inventaire vs comptabilité vs ETIC C6 |
| **Pertes clients masquées** | Clients douteux (3424) | Créances > 6 mois non provisionnées ; provisions sans action judiciaire | ETIC B6 ; existence de poursuites |
| **Asphyxie via les fournisseurs** | Fournisseurs (4411) | Délais de paiement anormalement longs | Tableau des délais audité par le CAC (loi 32-10) |
| **Résultat non pérenne** | CPC courant vs non courant | RN bénéficiaire porté par le non courant, courant déficitaire | Analyser le **résultat courant** (prévisible) |
| **Lissage par les provisions** | Provisions (15, 29, 39) | Reprises massives (719x/739x/759x) ou absence de dotations sur risques avérés | ETIC B5 : ouverture → clôture |
| **Décalage de charges/produits** | CCA (3491), PCA (4491) | Soldes anormalement élevés en fin d'exercice | Justification des comptes (spécialisation) |
| **Usure « arrangée »** | 28, 619 | Durées modifiées, dates de démarrage décalées | ETIC B2/B2bis + état A3 |
| **Distribution déguisée / risque fiscal** | CCA associés (4463) | Intérêts sur CCA alors que capital non libéré | Capital libéré (classe 1) vs taux max CGI |
| **Liquidité sous perfusion** | Trésorerie-passif (55) | Recours systématique aux découverts (5541) | TN = FRF − BFG ; TF module II |
| **Désinvestissement dissimulé** | 751 / 651 | Plus-value nette seule au CPC, sans montants bruts | Enregistrement distinct 751/651 + ETIC B3 |
| **Redressement fiscal sur provisions clients** | 3424 + liasse | Provisions déduites sans recours judiciaire dans les 12 mois | Tableau T22 de la liasse |
| **Fiscalité contre image fidèle** | 1130, 1351 | Amortissements dérogatoires importants, pas de réévaluation | ETIC A2 (dérogations) ; retraiter le bilan |

## La règle d'or
- **Un ratio = une relation entre deux lignes. Un poste = une décision passée. Un choix comptable = une intention.**
- L'analyste qui lit le bilan SANS l'ETIC lit une histoire sans les indices. L'analyste qui lit les deux lit l'histoire **et** les intentions.
- **Aucun ratio ne se lit isolément** : comparer dans le temps (analyse horizontale), au secteur, aux documents complémentaires (ETIC, rapport de gestion, rapport du CAC).
