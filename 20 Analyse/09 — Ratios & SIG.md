# 09 — Ratios & SIG

> [!quote] En une phrase
> La lecture chiffrée : la cascade **MB → VA → EBE → RN** + les ratios qui normalisent les grandeurs pour comparer dans le temps et entre pairs — *jamais isolément*.

## La cascade des SIG (ESG — TFR)

| Solde | Calcul simplifié |
| --- | --- |
| Marge brute (ventes en l'état) | Ventes de marchandises (711) − Achats revendus (611) |
| Production de l'exercice | Ventes de biens/services produits ± variation stocks ± production immobilisée (712 + 713 + 714) |
| Valeur ajoutée | MB + Production − Consommations externes (612 + 613/614) |
| EBE | VA + Subventions d'exploitation (716) − Impôts et taxes (616) − Charges de personnel (617) |
| Résultat d'exploitation | EBE ± autres produits/charges − dotations + reprises |
| Résultat courant | Résultat d'exploitation + Résultat financier (73 − 63) |
| Résultat net | Résultat courant + non courant − IS (67) |

## Structure, liquidité, rotation — formules du cours (vérifiées)
> ✅ **Formules et seuils tirés du cours d'Analyse financière (S4)** — plus `[standard]` :
- **Autonomie financière** = Capitaux propres / Total des dettes — **≥ 1** · **Indépendance financière** = CP / Financement permanent — **> 0,5 (50 %)** exigé par les banquiers · **Solvabilité générale** = Actif total / Dettes — nettement **> 1** · **Délai de remboursement** = Dettes de financement / CAF — **≤ 5 ans** (pratique bancaire)
- **Couverture des immobilisations** = Financement permanent / Actif immobilisé — **> 1**
- **Liquidité** : générale = AC/PC **> 1** · réduite = (AC − stocks)/PC **> 1** · immédiate = Disponibilités/DCT — pratiquement **toujours < 1** (trop élevée = sous-emploi)
- **Rotation** : DSO = (Clients et comptes rattachés / Ventes TTC) × 360 — **ne doit pas dépasser 90 jours** (sauf exception sectorielle) · DPO = (Fournisseurs et comptes rattachés / Achats TTC) × 360 — **idéalement > DSO** · DIO = (Stock moyen / Achats revendus) × 360
- **Rentabilité économique** = EBE (ou Résultat d'exploitation) / Actif économique · **Rentabilité financière** = Résultat net / Capitaux propres (référence : taux des placements sans risque)
