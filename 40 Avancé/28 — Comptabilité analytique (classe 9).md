# 28 — Comptabilité analytique (classe 9)

> [!quote] En une phrase
> Le miroir interne de la comptabilité générale : coûts d'achat, de production, de revient — **le résultat analytique (98) doit se réconcilier avec le résultat général (88)**.

## Quand l'utiliser
- **Coût complet** : méthode des sections homogènes + unités d'œuvre (centres approvisionnement, production, distribution).
- **Coûts partiels** : coût variable, seuil de rentabilité.
- **Contrôle budgétaire** : écarts sur quantités et sur coûts (96).
- **Valorisation des stocks** : les coûts de production analytiques (93/95) alimentent la valorisation des stocks du bilan → lien direct avec [[22 — Stocks]].
- ⚠️ Autonome : les comptes réfléchis (90) isolent la CAE de la CG — **hors états de synthèse légaux**.

## Les formules du cours (vérifiées — exemples du cours)
| Notion | Formule | Exemple du cours |
| --- | --- | --- |
| **Coût d'achat** | Prix d'achat + charges directes + charges indirectes d'achat | 65 000 + 225 = **65 225 DH** (100 t) |
| **Coût de production** | Coût d'achat des matières consommées + charges directes + indirectes de production | Frites : **28 754 DH** (avec en-cours initiaux − finaux) |
| **Coût de revient** | Coût de production vendus + charges directes + indirectes de distribution | — |
| **Équilibre du CIP** | SI + Entrées = SF + Sorties → Sorties = SI + E − SF | — |
| **CMUP fin de période** | (Coût SI + Coût entrées) / (Qté SI + Qté entrées) | (5 000×10 + 6 000×12)/11 000 = **11,09 DH** |
| **CUO** | Charges indirectes du centre / nombre d'unités d'œuvre | 3 335,18 / 800 = **4,1690 DH** |
| **Taux de frais** | Charges du centre / assiette de répartition | 1 677,51 / 79 698,65 = **2,10 %** |
| **MCV / Taux de MCV** | CA − CV ; (MCV/CA) × 100 | Taux = **55 %** |
| **Seuil de rentabilité** | CF / Taux MCV (ou CA × CF / MCV) | 530 / 0,55 = **963,64 DH** |
| **SR en quantité** | SR valeur / prix de vente unitaire (arrondi supérieur) | 963,64 / 0,90 = **1 071 pains** |
| **Marge / indice de sécurité** | CA − SR ; (marge × 100)/CA | 36,36 DH ; **3,64 %** |
| **Point mort** | (SR/CA) × m mois travaillés | 11,56 → **18 décembre** |
| **Imputation rationnelle** | Taux d'activité = prod. période/prod. normale ; CF imputées = CF réelles × taux | 90 % ; 3 000 × 90 % = **2 700 DH** ; sous-activité = **300 DH** |
