## 🎯 Comment lire un document de référence (mini-guide de stage)
> 📖 Un terme inconnu (AGO, greffe, après inventaire, point clé d'audit…) ? → [[📖 Lexique — Comprendre les rapports]]

1. **Commencer par l'opinion du CAC** (certification, réserves, points clés) → [[03 — Les Rapports d'Analyse Financière (Guide Complet)]]
2. **Bilan + CPC** 2 exercices → FRF/BFG/TN, SIG (MB → VA → EBE → CAF) → [[08 — FRF, BFG & TN (analyse dynamique)]] · [[09 — Ratios & SIG]]
3. **Tableau de financement** → emplois/ressources stables, la CAF
4. **ETIC** → méthodes d'évaluation, engagements, événements postérieurs
5. **T22 mental** → réintégrations probables → [[26 — Passage résultat comptable → fiscal]]
6. **Raconter l'histoire** → [[07 — Messages cachés (lecture entre les lignes)]]
