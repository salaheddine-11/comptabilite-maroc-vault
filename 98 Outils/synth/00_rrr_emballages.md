### Tableau 1 : Les 3 réductions commerciales (PCGE Maroc)
| Type de RRR | Sur Facture (Doit) | Hors Facture (Avoir) — Compte & Écriture |
| :--- | :--- | :--- |
| **Rabais** (défaut de qualité, retard) | Non comptabilisé séparément — enregistré pour le **Net Commercial** | **Acheteur** : Crédit **6119** (marchandises) ou **6129** (matières) · **Vendeur** : Débit **7119** ou **7129** |
| **Remise** (volume, fidélité) | Enregistré net d'écritures (Net Commercial) | Écriture d'avoir (TVA comprise) : **Client** D 4411 / C 6119/6129 + 34552 · **Frs** D 7119/7129 + 4455 / C 3421 |
| **Ristourne** (périodique globale) | Impossible sur facture d'origine (calculée a posteriori) | Même écriture d'avoir par 6119/6129 (client) et 7119/7129 (fournisseur) |

### Tableau 3 : Emballages et TVA (PCGE Maroc)
| Cas | Comptes PCGE | Écritures | TVA |
| :--- | :--- | :--- | :--- |
| **Consignation reçue (frs)** | **4425** (dettes pour emballages) | D 3421 / C 4425 | **Hors champ TVA** (caution contractuelle) |
| **Consignation versée (client)** | **3413** (créances pour emballages) | D 3413 / C 4411 | Non soumise à TVA |
| **Restitution au même prix** | Annulation réciproque | Contrepassation stricte 4425 (frs) / 3413 (client) | Aucune régularisation |
| **Restitution à prix < consignation** | **61317** (Mali client) · **71275** (Boni frs) | Frs : D 4425 / C 3421 + 71275 (HT) + 4455 · Client : D 4411 + 61317 (HT) + 34552 / C 3413 | Boni/Mali assimilé à une **location taxable (TVA 20%)** |
| **Non-restitution (vol/perte)** | **61231** (achat emb. perdu) · **71278** (vente accessoire) | Frs : D 4425 / C 71278 (HT) + 4455 · Client : D 61231/61232 (HT) + 34552 / C 3413 | Devient **vente d'emballage définitive** soumise à TVA de droit commun |

⚠️ 3 types d'emballages : **perdus** (61231, prix inclus dans le produit) · **récupérables identifiables** (2333, immobilisation) · **récupérables non identifiables** (61232 : bouteilles, caisses). La consignation est généralement exprimée **sans TVA** ; le montant de la consignation comporte de la TVA lors du boni/mali → décomposer HT/TVA. Les RRR doivent figurer **distinctement sur la facture** pour être déductibles de la base TVA (remise non mentionnée = non déductible).
