### Tableau 1 : Typologie et régime de TVA des subventions (PCGE Maroc)
| Type de subvention | Comptes principaux | Écritures types (Promesse → Encaissement) | Régime TVA Maroc |
| :--- | :--- | :--- | :--- |
| **Exploitation** | **7161** / **7168** (subv. reçues) · **34512** (subv. à recevoir) | D 34512 / C 7161 · D 5141 / C 34512 | **Hors champ** SAUF s'il s'agit d'un **complément de prix** directement taxable |
| **Équilibre** | **7561** / **7568** (subv. reçues) · **34513** (subv. à recevoir) | D 34513 / C 7561 · D 5141 / C 34513 | Généralement **hors champ TVA** (non liée à une exploitation tarifaire directe) |
| **Investissement** | **1311** (reçues) · **1319** (inscrites au CPC) | D 34511 / C 1311 · D 5141 / C 34511 | **Exclue du champ** (financement d'actifs stables, non exploitation) |

### Tableau 2 : Subventions d'investissement — Étalement et fiscalité (IS)
| Étape / Actif financé | Écritures de régularisation (PCGE) | Régime d'étalement (Art. 9-II du CGI) |
| :--- | :--- | :--- |
| **1. Encaissement** | D 5141 / C 34511 (créance) | Option d'étalement **irrévocable** excluant l'imposition immédiate |
| **2. Bien amortissable** | D 1319 / C **7577** (reprise) | Reprise calquée strictement sur le rythme de l'amortissement (quote-part subvention/immobilisation) |
| **3. Terrain (sans clause)** | D 1319 / C 7577 | Étalement par fractions égales sur **10 exercices** (⚠️ pas 5 ans) |
| **4. Clause d'inaliénabilité** | D 1319 / C 7577 | Reprise étalée sur le nombre d'années d'indisponibilité prévues au contrat |
| **5. Option sans étalement** | Pas de reprise 7577 | Imposition 100% l'exercice + droit à **amortissement exceptionnel** du montant de la subvention |

### Tableau 3 : Les 3 pièges des subventions au Maroc
| Piège | Risque / Erreur | Cadre réglementaire |
| :--- | :--- | :--- |
| **1. Équilibre vs Exploitation** | Confondre : équilibre → **7561 (non courant)** ; exploitation → **7161 (courant)** | Rubrique 75 vs 71 |
| **2. Aide remboursable** | Enregistrer en CP (1311) au lieu de… | **Dettes de financement (classe 14)** — obligatoire |
| **3. Charte de l'Investissement** | Croire que les primes échappent à l'étalement | Primes (territoriale, sectorielle, commune) éligibles à l'étalement art. 9-II ; cumulables jusqu'à **30%** du montant primable |
